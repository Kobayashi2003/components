# Layout & Navigation

Spatial organization and movement through an interface: layouts, menus, docks, and navigation models. Examples include [Morphing Action Menu](morphing-action-menu/README.md), [Magnifying Dock](magnifying-dock/README.md), and [Neubrutalist Task Board](neubrutalist-task-board/README.md).

Choose this category when placement or navigation is the main idea. Data editing belongs in **Forms & Input**; a control's direct manipulation can belong in **Interactions**.
