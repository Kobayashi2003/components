# Typographic Book

An interactive typographic book artwork with a constrained 3D camera.

## Usage

```tsx
import { TypographicBook } from './typographic-book';

export function Example() {
  return <TypographicBook backgroundColor="#f01808" />;
}
```

## Props

| Prop              | Default   | Description       |
| ----------------- | --------- | ----------------- |
| `backgroundColor` | `#f01808` | Background color. |
| `className`       | `''`      | Wrapper class.    |

## Notes

Drag to orbit; use the on-screen controls or keyboard to zoom and reset. The lettering is a fixed composition.
