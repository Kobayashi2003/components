# Geometry Light Lab

A WebGL2 lighting experiment with editable lights and geometric solids.

## Usage

```tsx
import { GeometryLightLab } from './geometry-light-lab';

export function Example() {
  return <GeometryLightLab />;
}
```

## Notes

Requires WebGL2. The embedded scene includes its own controls; drag lights, focus one and use arrow keys (Shift for larger steps), or use their numeric controls.
